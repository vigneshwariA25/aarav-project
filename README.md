# Aarav Wedding Hall — Premium React Website

A cinematic, luxury wedding hall website built with React + Vite.

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🛠 Tech Stack

- **React 18** + **Vite 5**
- **Tailwind CSS** — utility-first styling
- **Framer Motion** — page & component animations
- **Lenis** — buttery smooth scrolling
- **Swiper.js** — testimonial carousel
- **React CountUp** — animated statistics
- **React Icons** — icon library
- **React Intersection Observer** — scroll-triggered animations

## 🎨 Design

- **Palette**: Deep Olive · Sage Green · Champagne Gold · Ivory · Forest Green
- **Fonts**: Cormorant Garamond (headings) · Outfit (body) · Playball (accents)
- **Style**: Cinematic luxury · Glassmorphism · Parallax · Gold particle ambience
